# Xonix

Классический Xonix на pygame для одного или двух игроков на общем поле.

## Запуск

```bash
uv run main.py
```

Управление:

- В парной игре: первый игрок — `W` `A` `S` `D`, второй — стрелки. В одиночной обе раскладки управляют единственным маркером.
- `P` — пауза, `R` — рестарт раунда, `F11` или `Alt+Enter` — полноэкранный режим, `Esc` — выход в меню.
- В меню: `1` — один игрок, `2` — двое, `Esc` — выход.

Игра запускается в полноэкранном режиме и сама подбирает наибольший целый масштаб клетки под ваш экран, центрируя поле: на 1920x1080 клетка 13 px вместо справочных 6. В оконном режиме окно можно растягивать, масштаб пересчитается.

## Правила

- Поле 120x80 клеток, рамка — нейтральная земля. Справочный размер: клетка 6 px, окно 720x502 (480 на поле плюс полоса HUD).
- Выходя в море, маркер оставляет след. Любая клетка следа смертельна, своя и чужая.
- Вернувшись на землю, игрок забирает свой след, а затем всё море, до которого не дотянется ни один шар. Так закрываются петли, откусываются карманы с замурованными шарами, и не приносит территории открытый след соперника.
- У каждого 3 жизни; и в HUD, и на экране итогов они показаны красными сердечками — число сердечек равно числу оставшихся жизней. Смерть стирает след погибшего, поле остаётся как есть, возрождение — на последней клетке земли, где игрок стоял до выхода в море.
- Раунд кончается при 75% залитого игрового поля (6903 клетки) или когда у игрока кончились жизни. Победитель — по очкам, при равенстве объявляется ничья.
- В парном режиме приложение ведёт счёт побед по цветам за текущую сессию и показывает его крупно вверху экрана итогов только цифрами через двоеточие, красный:синий, например «2:1». Победа по очкам и победа по исчерпанию жизней соперника идут в счёт одинаково, ничья счёт не меняет. Счёт сбрасывается, когда новая партия запускается из меню, и сохраняется при рестарте раунда клавишей `R`, так что серию можно продолжать, не выходя в меню. Между запусками приложения счёт не сохраняется.
- Сложность растёт от прогресса: на 20%, 40% и 60% добавляется шар, шары ускоряются с 7 до 4 тиков на клетку. Игрок всегда идёт 3 тика на клетку.
- Новый шар рождается в дальней от обоих маркеров точке основной акватории и получает случайную из четырёх диагоналей: иначе все шары раунда уходили бы в одну сторону и один из игроков получал бы преимущество на старте.

Очки начисляются в момент захвата: 1 клетка — 1 очко. Земля в кадре монохромна, вклад игрока видно по вспышке захвата и по счётчику в HUD.

Игроки называются по цвету своего следа: первый — «красный», второй — «синий». Так подписаны счётчики в HUD, строка управления в меню и экран итогов: «У красного кончились жизни», «Синий победил — 57% против 21%», «Ничья — 36% против 36%», «Цель достигнута — 54%».

## Разработка

```bash
uv run pytest          # тесты ядра и ввода, без окна
uv run ruff check xonix tests
```

Структура:

- `xonix/core/` — симуляция без pygame: поле и заливка, шары, игроки, тик и раунд, фиксированный шаг времени.
- `xonix/render.py` — масштабирование, рисование, подписи HUD и тексты экрана итогов.
- `xonix/input.py`, `xonix/app.py` — раскладка клавиш, полноэкранный режим, состояния `MENU`/`PLAY`/`RESULT`.
- `xonix/assets/` — спрайты интерфейса; сердечко жизней (`heart.png`, 16x13) — пиксель-арт с прозрачным фоном.

Симуляция идёт фиксированными 60 тиками в секунду и не зависит от частоты кадров. Планирование и полные спецификации — в `openspec/changes/xonix-two-player/`.
