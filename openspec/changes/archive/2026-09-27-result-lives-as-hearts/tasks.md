## 1. Сердечки жизней на экране итогов

- [x] 1.1 Заменить в `xonix/render.py` текстовую строку `lives_text(result, solo)` на экране итогов на ряд сердечек: для каждого участвовавшего игрока нарисовать подпись по цвету и следующее за ней число сердечек, равное `result.lives[owner]`, тем же спрайтом `self.heart` и с тем же целочисленным масштабом, что и в HUD; проверить тестом в `tests/test_render.py`, что при 2 жизнях у красного и 0 у синего на экране итогов видны ровно два сердечка у подписи красного и ни одного у подписи синего
- [x] 1.2 Убедиться, что число жизней словами на экране итогов не печатается: строки вида «3 жизни», «1 жизнь» и «0 жизней» там отсутствуют; проверить тестом, что после отрисовки `draw_result` ни одна из этих формулировок не встречается на экране
- [x] 1.3 Сохранить читаемость при нуле сердечек: подпись по цвету остаётся видимой, когда жизней не осталось; проверить тестом, что подпись игрока с нулём жизней присутствует на экране
- [x] 1.4 Проверить одиночный режим: на экране итогов одиночного раунда показан ряд сердечек по числу оставшихся жизней единственного игрока; проверить тестом с `player_count=1`
- [x] 1.5 Проверить, что ряд сердечек целиком помещается по ширине при малом и большом окне и не накладывается на остальные строки; проверить тестом на нескольких размерах окна, включая минимальный
- [x] 1.6 Убедиться, что неиспользуемый хелпер `lives_text` (и относящийся к нему тест) не остались мёртвым кодом: либо удалить их, если больше нигде не используются, либо оставить только при наличии реального использования; прогнать `uv run ruff check xonix tests`
- [x] 1.7 Прогнать `uv run pytest -q` и убедиться, что изменения не сломали существующие тесты HUD, итогов и отрисовки пикселей
